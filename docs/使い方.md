# RowLog の使い方（部員向け）

練習の記録を出すアプリです。**1日1回、30秒**で終わります。

---

## 1. 最初にやること（1回だけ）

1. 主務から送られてきた URL をスマホで開く
2. **学年 → 自分の名前** を選ぶ。これで終わり。次から聞かれません
3. **ホーム画面に追加する**（毎回URLを探さなくて済みます）

| | やり方 |
|---|---|
| iPhone | 下の「共有」ボタン → **ホーム画面に追加** |
| Android | 右上の「⋮」 → **ホーム画面に追加** |

---

## 2. 毎日やること

練習が終わって **15〜30分後** にアプリを開いて、出すだけです。

すぐ後だと最後にやったメニューのきつさに引っぱられます。片付けが終わったころがちょうどいいです。

### 入れるもの

| | |
|---|---|
| 今日は？ | 実施 / 一部実施 / 欠席 / 休養 |
| 練習時間 | 分。アップとダウンを含めた実際の時間 |
| きつさ | 0〜10 を1つ押す |
| 計画どおりできた？ | 計画どおり / 短縮 / 中止 / 変更 |
| メニュー | 予定が最初から入っています。違うことをしたら押して消す |
| エルゴ | やった日だけ。距離・split・レート・ドラッグ |

**オフの日も出してください。** 「休養」を押して「出す」だけ、2タップです。

出さないと、休んだのか出し忘れたのか分からなくなります。それが一番困ります。

---

## 3. きつさ（0〜10）の目安

| | |
|---|---|
| 0 | 休んでいるのと同じ |
| 2 | 楽 |
| 3 | ふつう |
| 5 | きつい |
| 7 | とてもきつい |
| 10 | 限界。これ以上は無理 |

6・8・9も使えます。「5と7の間」なら6です。

**人と比べなくていいです。** 自分の中で、いつもよりきつかったか楽だったかが分かれば十分です。

---

## 4. よくある質問

**Q. 電波が入らないところで出せますか**
出せます。書いて「出す」を押せば端末に溜まり、電波が戻ると自動で送られます。
設定タブの「送信待ち」で残っている数が見られます。**アプリを消さないでください**（消えます）。

**Q. 出し忘れた日はどうしますか**
カレンダータブで、その日を押せば後からでも出せます。赤い ● が未提出の日です。

**Q. 練習が朝と夕方の2部あった日は**
1日1回にまとめてください。練習時間は合計、きつさはその日全体で1つです。

**Q. 明日の予定も出せますか**
出せます。カレンダーで未来の日を押すと予定の入力になります。

**Q. 間違えて出しました**
もう一度出し直してください。新しいほうを使います。

**Q. 名前を間違えて選びました**
設定タブの「別の人に変える」から選び直せます。

---

## 5. 何に使われるのか

練習時間 × きつさ で、その日の練習の重さを数字にします。
たとえば95分でRPE6なら570です。これを週ごとに足すと、その週にどれだけ練習したかが出ます。

それと20分エルゴの記録を並べて、**練習量と伸びの関係**を見ます。卒業研究のデータになります。

名前は解析には使いません。研究用の記号（B01、C14 など）に置き換えます。
